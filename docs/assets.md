# Assets: art and audio pipelines and provenance

This is the umbrella policy for every non-code file the game ships. The pipelines themselves are
documented by their owners: [art.md](art.md) (S4: dragon rig, icons, cosmetics, backgrounds),
[audio.md](audio.md) (S5: synthesis recipes, SFX, music) and [app.md](app.md) (S3: the reading
font, §7). The domain IDs that key assets are in [contract.md](contract.md).

## 1. Layout

| Path                             | Contents                                                          | Owner  |
| -------------------------------- | ----------------------------------------------------------------- | ------ |
| `assets/art/`                    | `catalog.json`, dragon recipes, palette, generated SVG            | S4     |
| `assets/backgrounds/`            | region, map and castle backgrounds (SVG first, painted later)     | S4     |
| `src/app/art/`                   | DOM-free SVG generators (rig, cosmetics, icons) used by the shell | S4     |
| `assets/audio/`                  | `manifest.json`, synthesized SFX and music, recipes               | S5     |
| `assets/fonts/`                  | DV Reading, a renamed Andika subset (SIL OFL), `OFL.txt`          | S3     |
| `scripts/art/`, `scripts/audio/` | the generators                                                    | S4, S5 |

## 2. What ships

`scripts/build.mjs` copies `assets/**` into the site **except authoring metadata**: `*.md`,
`*.prompt.txt`, `*provenance*.json`, `recipes/`, `source/`, `prompts/` directories and script files.
Everything it ships becomes part of the offline resource graph (exact bytes and SHA-256).

- Allowed file types are listed in `scripts/lib/site.mjs` (`KIND_BY_EXTENSION`); an unknown
  extension fails the build on purpose.
- Budgets: at most 32 MiB per file and 64 MiB for the whole site (the SDK's offline defaults), 4096
  files, no empty files. Prefer SVG, WebP and Ogg/Opus; keep music loops short.
- Licence files that must travel with a file (for example `OFL.txt` next to a font) are shipped.
  The build also writes `licenses.txt` with the game's and the Aegis SDK's MIT notices.

## 3. Interfaces with code

- **Art catalog** `assets/art/catalog.json`: the published list of art IDs (dragon recipes,
  characters, cosmetics, avatars, icons, emblems, regions; later bosses, stickers, backgrounds).
  Content refers to art only by these IDs (`region.background`, `dragon.rig`, `cosmetic.assetId`,
  `sticker.icon`, `sticker.frame`), and `scripts/validate-content.mjs` cross-checks them (report-only
  until art and content converge, then `--strict-art`). New stickers need no new art: the sticker
  composer renders `{ icon, color, frame }`.
- **Audio manifest** `assets/audio/manifest.json`: the published sound IDs. Rules know no sound IDs;
  the shell maps rules events (contract §12) to sounds.
- Keyed by canonical IDs (`ids.ts`): regions, dragons, bosses, stages, expressions, cosmetic slots,
  keeper avatars.

## 4. Provenance rules

Every shipped asset has recorded provenance that lets anyone reproduce or audit it.

1. **Generated by code** (SVG rig and icons, synthesized audio): the generator, its inputs (recipe,
   palette, seed) and the output digest are committed. A test regenerates the output and compares
   bytes, so the committed file is always the generator's output.
2. **AI-generated painted backgrounds**: commit the exact prompt (`<name>.prompt.txt`), the model and
   service, the date, the parameters, the person who approved it, and the output's SHA-256 in a
   `provenance.json` next to the images. No text in images, no real people, no trademarks; leave
   negative space for UI. The route is the Azure OpenAI gpt-image deployment used for the engine's
   showcase art; it is not available on every machine, so SVG backgrounds keep the game complete
   without it.
3. **Third-party files** (fonts): only permissive licences compatible with redistribution in a public
   repository and an offline web app (SIL OFL for fonts). Keep the licence text, the source URL, the
   version and the SHA-256.
4. **Nothing else**: no stock art, no samples from the internet, no recorded voices (read-aloud uses
   the device's local speech), no assets whose licence forbids redistribution.

## 5. Determinism across machines

Generated assets are committed with digests and checked in CI on Windows and Ubuntu, so generators
must produce **byte-identical output on every OS**:

- avoid `Math.sin`, `Math.cos`, `Math.exp`, `Math.pow` and friends in generators whose output is
  digest-checked: libm results differ across platforms. Use integer DSP, lookup tables or the
  deterministic math in `@aegis/core/math`;
- format numbers explicitly (fixed decimals), never with locale functions;
- sort object keys and file lists by code units; write LF line endings;
- seed any randomness from the recipe (`@aegis/core` `createPrng`).

## 6. Accessibility of assets

- Colour is never the only signal (feedback also changes shape, motion, sound and text).
- Art-dependent contrast is reviewed against the palette's accessible pairs (docs/art.md).
- Every meaningful image has an accessible name from the catalogs; decorative SVG is `aria-hidden`.
- Animations have reduced-motion variants; sounds have visual equivalents.
