# Pebble Brook playtest (1st grader)

Run: in `grades-slice-integration` worktree, `npm run serve -- --port 4320`, open http://localhost:4320/
(tablet on same Wi-Fi: use the PC's IP). Use a NEW keeper; existing children are untouched.

Before: grown-up adds keeper, picks **1st class**. Read-aloud is on automatically.

Watch for (note yes/no + comments):

1. Child understands "Which class?" step or needs help.
2. Egg choice (Dot / Hop / Nibble) — does the child enjoy choosing? Which one?
3. "How many dots?" — counts the dots on their own? Ten-frame layout clear?
4. 3 big choices / 2-digit keypad — easy to tap? Any mis-taps?
5. Read-aloud — voice understandable, not too fast, texts short enough?
6. - and − within 5, then within 10 — too easy / right / too hard? Where did they stall?
7. Ten Frame (level 5) — understands dragging/adding counters without explanation?
8. Memory Match (level 4) — fun or confusing?
9. Wisps boss — exciting or scary? Finished?
10. Map — finds Pebble Brook on the Lower Valley sheet; understands what glows next?
11. Session length — when did attention drop (minutes)?
12. Anything they asked a grown-up for help with (exact words help).
13. Would they want to play again tomorrow?

Grown-up area: change the child's class (2nd class should say "no lessons yet"; that's expected).

Send the notes back to the coordinator session; they decide tuning before the other four regions.
